如何設定 GitHub API 數據寫入？

透過 GitHub API，學生在遊戲中的成績會自動發送 Commit，直接寫入你儲存庫內的 scores.json 檔案：

  1. 確保 GitHub 儲存庫根目錄下有一個叫 scores.json 的檔案，初始內容可填入 []。
  2. 前往你的 GitHub 帳號 ➔ Settings ➔ Developer Settings ➔ Personal Access Tokens (Tokens classic / Fine-grained)。
  3. 點擊 Generate new token，在權限中勾選 repo (Contents: Read & Write)。
  4. 將生成的 Token (例如 ghp_xxxxx) 複製並貼上到教師控制台的 Token 欄位並點擊「儲存設定」。
  5. 學生每次遊戲完成後點擊「同步」，數據即會發送 COMMIT 自動寫入 GitHub！
