Google Sheet 數據寫入與修改設定指南

Google 試算表預設只允許「公開讀取 (CSV)」。若要讓同學的學習紀錄能成功上載並更新（修改舊成績），請按以下 4 個步驟完成免費設定：

  1. 打開你的 Google Sheet 試算表（確保第一列欄位為：班別 | 學號 | 完成題數 | 得分 | 更新時間）。
  2. 點擊上方選單的 「擴充功能 (Extensions)」 ➔ 「Apps Script」。
  3. 清空原有內容，將下方程式碼複製貼上：
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    var rows = sheet.getDataRange().getValues();
    var targetClass = String(data.studentClass).trim().toUpperCase();
    var targetId = String(data.studentId).trim();
    var foundRow = -1;
    
    for (var i = 1; i < rows.length; i++) {
      var rowClass = String(rows[i][0]).trim().toUpperCase();
      var rowId = String(rows[i][1]).trim();
      if (rowClass === targetClass && rowId === targetId) {
        foundRow = i + 1;
        break;
      }
    }
    
    if (foundRow > 0) {
      sheet.getRange(foundRow, 3).setValue(data.totalQuestions);
      sheet.getRange(foundRow, 4).setValue(data.score);
      sheet.getRange(foundRow, 5).setValue(data.updatedAt || new Date().toISOString());
    } else {
      sheet.appendRow([data.studentClass, data.studentId, data.totalQuestions, data.score, data.updatedAt || new Date().toISOString()]);
    }
    return ContentService.createTextOutput("SUCCESS").setMimeType(ContentService.MimeType.TEXT);
  } catch(err) {
    return ContentService.createTextOutput("ERROR: " + err.toString()).setMimeType(ContentService.MimeType.TEXT);
  }
}
  1. 點擊右上角 「部署 (Deploy)」 ➔ 「新增部署 (New deployment)」。
  2. 類型選擇 「網頁應用程式 (Web app)」，且「誰可以存取 (Who has access)」務必選擇 「任何人 (Anyone)」。
  3. 完成部署後，將獲得的 網頁應用程式網址 (Web App URL) 複製並貼回本控制台頂部的「Web App 網址」欄位即完成！
